# CLARO — Show Your Work. Understand Your Answer.

Offline-first educational reasoning platform (Phases 1–9).

## Features

- Offline-first with IndexedDB storage
- Local authentication prototype (LocalStorage)
- Structured answers (Answer, Key Points, Step-by-Step, Example, Confidence, Source Type, Why It Matters)
- Knowledge Library (Subjects → Books → Chapters → Topics → Questions)
- Student dashboard: Recent Questions, Saved Answers, Progress
- Responsive, accessible dark/light theme

## Run locally

1) Open `index.html` via a local server (e.g., VS Code Live Server or `python -m http.server`).
2) Create an account or continue as guest.
3) Try questions like:
   - What is normalization?
   - Explain Newton's second law.
   - What is an operating system?
   - Define Ohm's law.

## Testing

- Open `test.html` in a browser and check the console for self-test results.
- Manually test flows listed in Phase 9 checklist.
